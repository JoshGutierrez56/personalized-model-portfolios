The investment decision

For the No gold account, choosing Lower turnover rather than Minimum risk allocation saved only about $110 annually per constant $1m at the assumed cost rate, while accepting about 27bp more realized tracking risk.

Prefer tighter tracking when mandate fidelity is the priority. Choose lower turnover only when the client's objective justifies the additional risk. A technical PASS is not an investment approval.

What these results do—and do not—establish

Evidence

  • Eight ETFs; 32,192 CRSP observations, 2010–2025 source history.
  • 2014–2025 evaluation, 30 account/method paths and 4,320 decisions.
  • Self-financing trades, prior-close decisions, drifting holdings and independently linked return contributions.
  • Traceable block → diagnosis → correction → retest workflow.

Boundaries

  • Current-vintage, retrospectively selected universe; already-exposed historical sample.
  • No live orders, actual clients, tax-lot engine, stock-level factor model or alpha claim.
  • Injected failures are tests, not real production incidents.
  • Licensed source rows and detailed security-day ledgers remain private.
Run provenance and tolerances

Tolerance definitions are in oversight_contract.json. Dollar/return/weight units differ; row-count checks permit zero missing rows. “Max error” for boolean controls is 0 or 1, not a financial amount.
